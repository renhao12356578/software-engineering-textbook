校对内容

你需要做什么？

核心任务

图片核查

  • 图片是否缺失——源码中有引用但文件不存在
  • 图片内容是否与原书对应——截图位置错误、张冠李戴
  • 图片编号是否正确——fig_4_1.png 是否真的对应图 4-1
  • 图片清晰度是否可接受——模糊、裁剪不完整
辅助任务

文字校对

  • 漏字、错字、标点错误
  • 章节引用、图表编号与原书是否一致
  • 公式、代码块格式是否正确
每章工作量约 1–3 小时，按章独立认领，互不干扰。无需一次完成全部章节。

参与流程

三步加入

认领章节

在 GitHub 开一个 Issue，标题写 [校对认领] 第 X 章，说明你想负责的章节。
→ 点此开 Issue

Fork 仓库并校对

Fork 后，对照原书 PDF，在对应 chapters/chXX.typ 文件中直接修改，或用注释标注问题。
→ 查看仓库

提交 Pull Request

PR 被合并后，你的名字会自动出现在 README 贡献者列表中，无需手动操作。

本项目为学习性质的开源整理，无报酬。
